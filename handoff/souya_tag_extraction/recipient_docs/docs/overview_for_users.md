# CADタグ・属性抽出のしくみ（ご説明用・概要）

この資料は、プログラムやCADの内部処理に詳しくない方向けに、この仕組みが何をするものかを、専門用語とプログラムのコードを使わずに説明したものです。

社内説明やお客様説明にそのまま使えるよう、この1冊だけで内容が分かる構成にしています。実際に組み込む担当者向けの手順や入出力の詳細は、同じフォルダーの別資料にまとめています。本資料を読んだうえで、必要になった資料だけを開いてください。

## 1. ひとことで言うと何をするものか

設計で作成されたCADのファイルを読み取り、その中に書かれている情報を自動で取り出して、あとから探しやすくするための見出しを付ける仕組みです。

- 取り出す情報の例: 図面番号、図面名、材質、質量、寸法や公差の有無、溶接の指示、塗装の指示
- 付ける見出しの例: 「客先:顧客A」「装置:搬送装置」「材質:ステンレス」「溶接指示あり」

これまで人が図面を1枚ずつ開いて台帳へ書き写していた作業を、ファイルから機械的に読み取る形へ置き換えることが目的です。

## 2. 導入前と導入後で何が変わるか

| 場面 | これまでのやり方 | この仕組みを使った場合 |
|---|---|---|
| 過去の図面を探す | 担当者の記憶とフォルダー名をたどる | 客先、装置、材質などの見出しで絞り込む |
| 図面の一覧・台帳を作る | 図面を開いて必要な項目を手入力する | ファイルから読み取った値をそのまま利用する |
| 値の出どころを確かめる | 元の図面を開いて目視で確認する | どの値を根拠にしたかが記録として残る |
| 表記のばらつき | 同じ材質でも書き方が人によって違う | 同じ意味の言葉をまとめて扱える |
| 担当者以外が探す | 聞かないと分からないことが多い | 見出しから当たりを付けられる |

## 3. 資料に出てくる言葉

| 言葉 | 意味 | 補足 |
|---|---|---|
| CADファイル | 設計図そのもののデータ | 本仕組みではICAD、STEP、DXFの3種類を扱う |
| 属性 | 図面に書かれている個々の情報 | 図面番号、図面名、材質、質量など |
| タグ | 検索や分類に使う短い見出し | 「客先:顧客A」「溶接指示あり」など |
| 正規化 | 表記のばらつきをそろえ、同じ形に整えること | 半角と全角、余分な空白などをそろえる |
| 辞書 | 「この言葉が出てきたらこの見出しを付ける」という対応表 | 運用しながら言葉を増やせる |
| 根拠 | そのタグを付けるもとになった図面上の値 | あとから確認できるように結果へ残す |
| 確からしさ | その判定がどれくらい確実かの目安 | 低い場合は候補として扱う |

## 4. 使うときの流れ

```text
[1] CADのファイルを渡す
      ↓
[2] ファイルの中身を読み取る（元のファイルは変更しない）
      ↓
[3] 表記をそろえて共通の形に整える
      ↓
[4] 辞書と照らし合わせてタグを付ける
      ↓
[5] 結果を受け取る（検索や一覧への保存はご利用のシステム側）
```

1. 対象のCADファイルを指定します。
2. ファイルに書かれている文字、寸法、部品構成、材質などを読み取ります。元のファイルは開いて読むだけで、書き換えません。
3. 入力の種類ごとに書き方が違うため、共通の形へ整えます。
4. 辞書と照らし合わせ、客先や装置などの見出しを付けます。同時に、その見出しを付けた根拠も残します。
5. 結果を受け取ります。この結果をどこへ保存し、どの画面で見せるかは、組み込み先のシステム側で決めます。

## 5. どんな情報を取り出せるか

元の図面に書かれている範囲で、次のような情報を取り出します。書かれていない項目は取り出せません。

| 分類 | 取り出す情報の例 |
|---|---|
| 図面の基本情報 | 図面番号、図面名、改訂、尺度、用紙サイズ |
| 担当・日付 | 設計者、検図者、承認者と、それぞれの日付 |
| 業務の区分 | 客先、案件、装置の種類、ユニット |
| 部品と材料 | 部品名、部品の構成、材質、質量、体積 |
| 図面上の指示 | 寸法、寸法公差、幾何公差、溶接の指示、塗装の指示、熱処理と硬度 |
| ファイルの出どころ | ファイル名、保存場所、ファイルの種類 |

取り出せる項目は、渡すファイルの種類によって変わります。

| ファイルの種類 | 特徴 | 必要な環境 |
|---|---|---|
| ICAD | 材質、質量、部品の構成まで最も詳しく取り出せる | ICADが使えるWindowsのPC |
| STEP | 3次元の形状と部品構成が中心。材質などは残っていないことがある | 一般的なPCで処理できる |
| DXF | 2次元の文字、寸法が中心。書かれていない意味情報は取り出せない | 一般的なPCで処理できる |

STEPとDXFは、CADの情報をやり取りするために変換された形式です。変換の時点で失われた情報は、あとから復元できません。正式な材質や部品の区分が必要な場合は、ICADのファイルから読み取ります。

## 6. 結果のイメージ

次は説明用の架空例です。実際の図面の値ではありません。

| 付いたタグ | 根拠になった値 | 確からしさ |
|---|---|---|
| 客先:顧客A | 保存先フォルダー名 | 中 |
| 装置:搬送装置 | 図面名の文字列 | 高 |
| 材質:ステンレス | 部品に設定された材質名 | 高 |
| 溶接指示あり | 図面上の溶接記号 | 高 |
| 熱処理:焼入れ | 図面上の注記 | 中 |

このように、タグと一緒に「なぜそう判定したか」が残ります。結果を見た人が、元の図面を開かずに妥当性を確認できるようにするためです。

## 7. 分からないものは分からないと答えます

この仕組みは、読み取れなかった項目を推測で埋めません。

- 読み取れない項目は、空欄のままにします。
- 「値が0」と「分からない」を区別します。確認できない数値を0として扱いません。
- 候補が複数見つかった場合は、どれか1つに決めずに候補として残します。
- 読み取りに失敗した内容は、注意メッセージとして結果に残します。

推測で埋めると、探すときに誤った図面へ行き着き、かえって確認の手間が増えます。空欄であれば、あとから人が補うか、辞書に言葉を足して読み取れるようにできます。

## 8. できること・できないこと

| 内容 | この仕組み | 補足 |
|---|---|---|
| CADファイルからの情報の読み取り | 含む | ICAD、STEP、DXFに対応 |
| 表記をそろえる処理 | 含む | 共通の形へ整える |
| タグ付けと根拠の記録 | 含む | 辞書と図面の値を照らし合わせる |
| 読み取った結果の保存 | 含まない | 保存先はご利用のシステム側で用意する |
| 検索画面、一覧画面 | 含まない | 画面はご利用のシステム側で用意する |
| 文書検索AIとの連携 | 含まない | 結果を渡す形での連携になる |
| 元の図面の書き換え | 行わない | 読み取りのみ |

この仕組みは、あくまで「図面から情報を取り出してタグを付けるところまで」を担当します。取り出した結果をどこへ保存し、どのように見せるかは、組み込み先のシステムで決めていただく前提です。

## 9. 動かすために必要なもの

| 使い方 | 必要な環境 |
|---|---|
| ICADのファイルから直接読み取る | ICADが使えるWindowsのPC |
| ICADのファイルをSTEPまたはDXFへ変換する | ICADが使えるWindowsのPC |
| STEPまたはDXFから読み取る | 一般的なPC。ICADは不要 |
| 読み取った結果を整えてタグを付ける | 一般的なPC。ICADは不要 |

インターネットへの接続は不要です。外部のAIサービスへ図面の情報を送る処理は含んでいません。図面の情報は、動かしているPCとご利用のシステムの中だけで扱われます。

## 10. よくあるご質問

質問: 元の図面が書き換わることはありませんか。

回答: ありません。ファイルは読み取るだけで、保存や上書きは行いません。

質問: 100%正しく読み取れますか。

回答: いいえ。読み取れるのは図面に書かれている範囲までです。書き方が特殊な場合や、図面に書かれていない情報は取り出せません。そのため、確実に判断できないものは空欄にする方針にしています。

質問: 読み取れなかった項目はどうなりますか。

回答: 空欄のまま残り、必要に応じて注意メッセージが付きます。運用では、あとから人が値を補うか、辞書に言葉を足して読み取れるようにします。

質問: 新しい客先名や部品名を覚えさせられますか。

回答: できます。辞書に言葉を追加すると、次回以降の読み取りから反映されます。プログラムの変更は不要です。

質問: なぜ推測で埋めてくれないのですか。

回答: 誤った値が入ると、探すときに誤った図面へ行き着き、確認の手間が増えるためです。空欄であれば、不足していることがその場で分かります。

質問: ICADが入っていないPCでも使えますか。

回答: STEPとDXFの読み取りは、ICADがなくても動かせます。ICADのファイルを直接読み取る場合と、ICADのファイルを変換する場合は、ICADが使えるWindowsのPCが必要です。

質問: 導入すればすぐに図面を検索できるようになりますか。

回答: この仕組みだけでは検索画面までは用意されません。取り出した結果を保存する場所と、それを見せる画面をご利用のシステム側で用意していただくと、検索として使える状態になります。

質問: 図面の情報が社外に出ることはありませんか。

回答: ありません。外部のAIサービスや外部のサーバーへ図面の情報を送る処理は含んでいません。
